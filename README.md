# PujaMitra 🪔

**Find and book verified pujaris for Hindu ceremonies — Hassan district, Karnataka.**

> The right purohit, for the right ceremony, without the wrong surprises.

---

## What is PujaMitra?

Families searching for a pujari today rely on word-of-mouth, phone calls to temples, or asking neighbours. PujaMitra brings every verified pujari in the district onto one platform — searchable by ceremony type, language, availability, and distance.

---

## Screens

| Screen | What it does |
|--------|-------------|
| **Home** | Featured pujaris, ceremony quick-select, search entry |
| **Search / Filter** | Filter by ceremony, language, rating, price, availability |
| **Pujari Profile** | Bio, specialties, reviews, pricing, booking CTA |
| **Booking** | Select date, ceremony, confirm details |
| **Confirmation** | Booking summary with contact info |
| **My Bookings** | View all upcoming and past bookings |
| **Saved** | Shortlisted pujaris |
| **Join as Pujari** | Onboarding form for new pujaris |
| **Pujari Dashboard** | Manage bookings, availability, profile |
| **Admin** | Platform management view |

## Tech Stack (Prototype)

- **React** — functional components + hooks
- **Lucide React** — icons
- **Fraunces** (serif display) + **Inter** (body) — Google Fonts
- No backend yet — demo data, all state in-memory
